Place icon images here.

- Directory: `assets/icons`
- File naming: use instrument/category name, normalized to PNG
  - Spaces and dots become underscores
  - Example: `Piano.png`, `Acc_Gtr.png`, `El_Piano.png`
- Recommended size for popup icon slot: 58x58 px

During build, contents of `assets/icons` are copied into the app bundle Resources at `Resources/assets/icons`.
